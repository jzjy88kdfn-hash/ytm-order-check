# 山﨑塗装_発注金額査定ツール

iPhone主体・発注金額確認専用のPWAです。外部ライブラリ・広告・アクセス解析・DBは使用しません。

## 公開方法（GitHub Pages）
1. このZIPの中身をリポジトリ直下へ配置。
2. `main` ブランチへ反映。
3. GitHub → Settings → Pages → Build and deployment → `Deploy from a branch`。
4. Branch `main` / Folder `/(root)` を選択して保存。
5. 公開URLをiPhoneのSafariで開き、共有 →「ホーム画面に追加」。

## 前提条件
- 一般課税
- 発注先：インボイス登録事業者
- 消費税率：10%

## 計算仕様
- 発注金額（税込）＝受注金額（税込）×発注率（1円単位四捨五入）
- 消費税相当額＝税込金額×10/110（1円未満切捨て）
- 消費税差額（概算）＝売上消費税相当額−発注消費税相当額
- 消費税差引後粗利益（概算）＝受注−発注−消費税差額

※所得税・住民税・事業税・現場経費等は含みません。実際の納税額は年間集計で確定します。

## データ
受注金額・計算結果はサーバー保存しません。標準発注率のみブラウザのlocalStorageへ保存します。
